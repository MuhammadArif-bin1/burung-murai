# API Route Handlers

Semua endpoint backend MuraiMarket disimpan di bawah folder `app/api/` agar domainnya
mudah dipisahkan dan dirawat. Struktur yang direncanakan:

- `app/api/auth/`
- `app/api/birds/`
- `app/api/categories/`
- `app/api/favorites/`
- `app/api/transactions/`
- `app/api/payments/`
- `app/api/admin/`
